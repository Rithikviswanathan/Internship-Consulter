# 🤖 Internship Assistant Chatbot

A beautiful, interactive chatbot designed to help you succeed in your internship!

## Features

- 💬 **Smart Conversations** - Get advice on tasks, skills, networking, feedback, and challenges
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- ⚡ **Quick Replies** - One-click suggestions for common questions
- 📱 **Responsive** - Works perfectly on desktop and mobile
- 🔄 **Real-time Chat** - Instant responses with typing indicators

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```

3. Open your browser and go to:
```
http://localhost:5000
```

## Topics Covered

- 📋 **Tasks** - How to manage and complete internship tasks
- 💪 **Skills** - What skills to develop during your internship
- 🤝 **Networking** - How to build professional connections
- 📝 **Feedback** - How to seek and handle feedback
- 🆘 **Challenges** - How to overcome obstacles
